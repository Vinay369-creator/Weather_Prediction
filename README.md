## Weather App

This project is implemented using the OpenWeatherMap API to fetch real-time weather information for cities.

### API Configuration

To make API requests, you must create your own API key from the OpenWeatherMap website.

#### Steps

1. Create an account on OpenWeatherMap.
2. Generate your API key from your account dashboard.
3. Replace the existing API key in the project with your own API key.

Without a valid API key, the application will not be able to retrieve weather data.

### Features

* Search weather by city name
* Real-time temperature data
* Weather condition information
* Dynamic weather icons
* User-friendly interface
